# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.1.0] - 2026-03-26

### Changed

- The music toast will now resize dynamically depending on the length of song titles.
- Added support for mods that use the 1.21.6+ localization format.
